# รหัสผ่านในแท็บ User อัปเกรดเป็น hash (SHA-256 + salt) อัตโนมัติเมื่อล็อกอิน

แท็บ `User` เดิมเก็บรหัสผ่านเป็นข้อความธรรมดา และเจ้าหน้าที่ยังเพิ่มผู้ใช้ด้วยการพิมพ์ลงชีตเอง แอปจึงรับได้ทั้งสองแบบ: ค่าที่ขึ้นต้นด้วย `sha256$` ถือเป็น hash (SHA-256 + salt) hash ค่าอื่นเทียบแบบข้อความธรรมดา และเมื่อล็อกอินสำเร็จด้วยแบบหลัง จะเขียน hash ทับทันที ทำให้ย้ายข้อมูลได้โดยไม่ต้องรีเซ็ตรหัสใคร แลกกับการที่ผู้ใช้ใหม่ที่ถูกพิมพ์ลงชีตจะมีรหัสข้อความธรรมดาค้างอยู่จนกว่าจะล็อกอินครั้งแรก

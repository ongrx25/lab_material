# เว็บเข้าถึง Google Sheet ผ่าน Service Account ฝั่งเซิร์ฟเวอร์

แอปต้องเขียนข้อมูลลงชีต จึงใช้ Service Account ของ Google Cloud ที่ได้สิทธิ์ Editor เฉพาะไฟล์นี้ และเรียก Sheets API จากเซิร์ฟเวอร์ Next.js เท่านั้น เราไม่เลือก Google Apps Script Web App เพราะ URL ของมันเปิดสาธารณะและต้องทำระบบกันการเรียกเอง และไม่ให้เบราว์เซอร์เรียก API ตรง เพราะจะต้องเปิดเผยกุญแจหรือให้ผู้ใช้ทุกคนล็อกอิน Google ผลที่ตามมาคือชีตเลิกแชร์แบบสาธารณะได้ และต้องตั้งค่า Service Account หนึ่งครั้ง

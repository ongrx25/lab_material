# ความต้องการระบบ (จากผู้ใช้ 22 ต.ค. 2569)

ระบบ "บริหารจัดการ เบิก-จ่าย และคลังวัสดุอัจฉริยะ" กลุ่มงานเทคนิคการแพทย์ โรงพยาบาลวาริชภูมิ
เว็บแอป Responsive (มือถือ + คอมพิวเตอร์) เชื่อมกับ Google Sheet

## 1. ผู้ใช้
- เพิ่มผู้ใช้พร้อมรหัสผ่านแยกรายบุคคล ต้องล็อกอินก่อนใช้งาน และระบุตัวตนทุกครั้งที่เบิกจ่าย

## 2. รับเข้า (Check-in)
- ค้นหาด้วยชื่อบางส่วน / รหัสสินค้าบางส่วน / สแกนบาร์โค้ดด้วยกล้อง
- ระบุ จำนวน, Lot, วันหมดอายุ, บริษัท, ราคาต่อหน่วย
- นับยอดเข้าและอัปเดตคงเหลือทันที

## 3. เบิกจ่าย (Check-out)
- ช่องค้นหาอัจฉริยะ แสดงผลทันทีขณะพิมพ์
- "รายการที่ใช้บ่อย" อยู่บนสุด กดบันทึกเบิกได้ทันที
- แก้รายการ / จำนวน / เพิ่ม-ลด ได้ตลอด
- เบิกผ่านมือถือหรือคอมโดยสแกน QR Code ประจำจุดเบิกจ่าย ตัดสต็อกอัตโนมัติ

## 4. ใบเบิกวัสดุ (A4 หนึ่งหน้า, พิมพ์ / ส่งออก Word / Excel)
1. บรรทัดที่ 1: ใบเบิกวัสดุ กลุ่มงานเทคนิคการแพทย์
2. บรรทัดที่ 2: โรงพยาบาลวาริชภูมิ
3. บรรทัดที่ 3: ซ้าย = เลขที่เบิก (รันอัตโนมัติ), ขวา = วันที่และเวลา (เลือกได้)
4. ตาราง: ลำดับ, รายการ, หน่วย, จำนวนที่ต้องการเบิก, จำนวนคงเหลือ, Lot, วันหมดอายุ, มูลค่า, หมายเหตุ — เรียงตามลำดับที่เลือก
5. ท้ายตาราง: มูลค่ารวม (บาท)
6. ท้ายใบ: ลงชื่อ ผู้เบิก (บังคับ) / ผู้จ่าย / ผู้ตรวจสอบ — แต่ละช่องมีตำแหน่งและวันที่ พิมพ์เองหรือเลือกจากรายชื่อที่เคยใช้
7. รายการเยอะเกินหนึ่งหน้า: ขึ้นใบใหม่ โดยทุกใบมีข้อมูลครบ

## 5. แจ้งเตือนและการจัดลำดับ
- ตั้งจำนวนขั้นต่ำ (Safety Stock) รายรายการ
- แจ้งเตือนเมื่อต่ำกว่าขั้นต่ำ และก่อนหมดอายุ 6 เดือน
- Web Notification บนสมาร์ทโฟน
- รายการที่ต้องแจ้งเตือนขึ้นเป็นอันดับต้นๆ เรียงตามความเร่งด่วน

## 6. สั่งซื้อและรายงาน
- ปุ่มเดียว "ดูรายการที่ต้องสั่งเพิ่ม" พร้อมจำนวนที่ควรสั่ง คำนวณจากยอดใช้เฉลี่ยย้อนหลัง
- รายงานสรุปรับ-จ่ายและคงเหลือรายเดือนอัตโนมัติ
